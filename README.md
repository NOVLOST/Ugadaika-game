# Ugadaika-game
Консольная игра ,вводим слово и побукве отгадываем .


Данная программа реализует игру «Угадай буквы в слове». Её работа происходит следующим образом:

1. Пользователь вводит одно слово (сохраняется в массив `remind_word`).
2. Программа строит словарь (`unordered_map`), в котором ключами являются все **уникальные** буквы введённого слова, а значениями — флаги `false` (означают, что буква ещё не угадана).
3. Затем запускается бесконечный цикл, в котором пользователю предлагается вводить по одной букве.
   - Если введённая буква **присутствует** в слове (т.е. есть в словаре) и ещё не была угадана (`false`), она отмечается как угаданная (`true`), и выводится сообщение «Буква угадана!».
   - Если буква есть в слове, но уже была угадана ранее, выводится «Буква уже была угадана.»
   - Если буквы в слове нет, выводится «Вы ввели букву, которой нет в слове.»
4. После каждого ввода программа проверяет, все ли буквы из словаря стали угаданными (все значения `true`). Если да – выводится поздравление и цикл прерывается (игра завершается).

**Важные особенности:**
- Учитываются только **уникальные** буквы слова – если в слове есть повторяющиеся буквы, достаточно угадать её один раз.
- Регистр букв **имеет значение**: символы `'A'` и `'a'` считаются разными.
- Программа не отображает текущее состояние слова (например, с заменой неугаданных букв на прочерки), а лишь сообщает о результате каждой попытки.
